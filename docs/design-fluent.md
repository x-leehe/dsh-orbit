# DSH-Orbit 设计规范 · Fluent(WinUI 3) × Material 3

本文件是界面改版的唯一事实来源。任何界面改动都要先对照这里，再动代码。

设计语言取自两处，冲突时以 WinUI 3 为准：

- [WinUI 3 概览](https://learn.microsoft.com/en-us/windows/apps/winui/winui3)
- [Geometry in Windows（圆角）](https://learn.microsoft.com/en-us/windows/apps/design/style/rounded-corner)
- [Typography in Windows（版式阶梯）](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography)
- [Content layout and spacing](https://learn.microsoft.com/en-us/windows/apps/design/style/spacing)
- [Color in Windows](https://learn.microsoft.com/en-us/windows/apps/design/style/color)
- [Material 3](https://m3.material.io/)：状态层、抬升、形状阶梯、涟漪

## 1. 硬性规则

1. **界面文件里不允许出现颜色字面量**。所有颜色都从 `Fluent` 取（`Color.FromArgb` 只能出现在 `Fluent.cs`）。
2. **最小字号 12px**（WinUI 的下限）。正文 14px，卡片标题 20px，大标题 28px。
3. 所有尺寸走 **4px 网格**，常用间距 `4 / 8 / 12 / 16 / 24 / 32`。
4. 圆角只有四档：控件 `4`、卡片/浮出层 `8`、M3 磁贴 `16`、药丸 `999`。
5. 文字层级只用三级：`TextPrimary` / `TextSecondary` / `TextTertiary`，不要自造灰度。
6. 悬停/按下用 `VisualState` + `Fluent.OverState` 的 8%/10% 状态层，不要写死高亮色。
7. 强调色一律取 `Fluent.AccentFill`（跟随系统强调色），不要写死 DSH 蓝。
8. 高 DPI：所有像素值经 `S(v) = round(v * DeviceDpi / 96)` 缩放；字体用 `Fluent.Font(role, strong, dpiScale)`。
9. 每个 `Paint` 开头调一次 `Fluent.AntiAlias(g, crisp: true)`；**分层 / 透明表面**（挂件、托盘菜单、弹层）不传 `crisp`，保持灰度抗锯齿。

### 2.2 版式

| 角色 | 字号/行高 | 用途 |
|---|---|---|
| `Caption` | 12/16 | 标签、状态、次要信息 |
| `Body` | 14/20 | 正文、菜单项、按钮 |
| `BodyLarge` | 18/24 | 强调正文 |
| `Subtitle` | 20/28 | 卡片标题、对话框标题 |
| `Title` | 28/36 | 页面标题、端口号 |
| `Display` | 40/52 | 大号展示（新标签页主标题） |

字体族：`Segoe UI Variable Text`（正文）/ `… Text Semibold`（强调）/ `… Display`（大标题）/ `… Small`（小字）。
中文由系统字体链自动回落，无需指定。Win10 回落到 `Segoe UI`。

文字渲染（每个 `Paint` 开头都要调）：`Fluent.AntiAlias(g, crisp: true)` → `ClearTypeGridFit`，只给**不透明窗口**
（外壳、对话框、安装器）。GDI+ 的灰度抗锯齿会把 12px 中文的笔画压在半个像素上，看起来发虚；
ClearType 把笔画放进像素里，明显更实，而且布局坐标不是整数像素也不受影响。
**透明 / 逐像素分层表面**（桌面卡片、托盘菜单、搜索引擎弹层）必须留 `crisp: false`（默认 `AntiAlias`）：
ClearType 需要不透明底色，画在透明面上会出彩边。
核对方式：`RenderPreview.exe <目录> --only chrome` 会产出标题栏 + 工具条的 1:1 图和 4 倍放大图。

### 2.3 海拔（M3）

| 级别 | 用途 | 阴影 |
|---|---|---|
| 0 | 页面内元素 | 无 |
| 1 | 悬停中的磁贴、工具提示 | 6 环，5% |
| 2 | 浮出层、卡片的悬停态 | 11 环，4% |
| 3 | 桌面悬浮卡片 | 17 环，3% |

### 2.4 动效

- 悬停：83ms 进入 / 167ms 退出
- 涟漪（M3）：220ms，`EaseOut`
- 页面/标签切换：250ms，`EaseEmphasized`（≈`cubic-bezier(0.2,0,0,1)`）
- 挂件接力变形：图标让位 120ms → 槽位长大 250ms（`EaseEmphasized`）→ 内容 140/180/220/260ms 错峰、490ms 全亮；
  收起 167ms、图标再现 140ms。挂件旋转：运行 8s/圈、启动中 2.4s/圈。

## 4. 界面规格

### 4.1 桌面挂件（贴边图标 ⇄ 浮层，接力变形）

挂件不是"常驻卡片"。它平时是屏幕边缘的一枚小图标，**运行中自己转**；鼠标靠近才长大成信息浮层。
设计取舍：桌面上真正需要随时看到的只有两件事——**它活着吗**、**我还要不要再动手**。

```
常态（收起=拉手）          贴边（6×28 拉手）        悬停长大（浮层）
        ┌────┐                    ┃         ┌──────────────────────┐
        │ ◉  │                    ┃ 6×28    │ ◉ DSH-Orbit          │
        └────┘                    ┃ 状态色   │ 127.0.0.1:3080       │
       44×44                    光晕 8%     │ profile web · 插件 … │
                                              │ ──────────────────── │
                                              │ 运行时长   02:06:22   │
                                              │ 今日已用   ¥0.6400    │
                                              │        停止   打开    │
                                              └──────────────────────┘
```

**尺寸**（96 dpi；窗口 = 浮层 + 2×26 阴影边距）

| 元素 | 尺寸 | 圆角 | 其它 |
|---|---|---|---|
| 图标 | 44×44 | 内侧两角 16、贴屏两角 **0**（贴左时镜像） | `Layer` 底 + 1px `StrokeStrong` + 海拔 2 |
| **拉手**（收起态） | **6×28** | 内侧两角 **4**（`RControl`）、贴屏两角 0 | **状态色实心** + 同色 8% 光晕（外扩约 8px）；悬停提到 14% 并外扩 2px，**尺寸不变** |
| 浮层 | 320×228 | 16 四角 | `Layer` 底 + 1px 描边 + 海拔 3，内边距 16 |
| 窗口 | 372×280 | — | 图标与浮层共用；贴屏侧让阴影落到屏外 |

收起态不是"消失"，而是留一根 **6×28 的拉手**贴在屏幕边缘、垂直对齐图标中心。
用户必须看得见"它收在哪"——只留一条 4px 的缝，找不回挂件的人会以为它被关了。
拉手同时承担状态语义（颜色同下表），所以收起时也能一眼看出服务是活着还是挂了。
不用药丸圆角：6px 宽上 999 会变成半圆，看着像系统滚动条。

**图标 = 状态 + 活性**（全挂件唯一的状态色载体）

| 状态 | 颜色 | 动效 |
|---|---|---|
| 运行中 | `Success` | 标记 **8s/圈**匀速旋转 |
| 启动中 | `Caution` | **2.4s/圈**（转得急 = 还没就绪） |
| 已停止 | `Caution` | 静止 |
| 异常 | `Critical` | 静止 |
| 鼠标穿透 | 不变 | 不变（窗口带 `WS_EX_TRANSPARENT`，探照灯把光标处挖成渐变透明） |

标记为 `OrbitMark` 的**三段 74° 弧 + 中心点**，20×20、stroke 1.5；**不用鲸鱼叠层**——
鲸鱼在 ≥20px 时会在弧上切出楔口，看起来像渲染瑕疵（只在 125% 以上 DPI 触发）。

**浮层内容**（自上而下，全部 4px 栅格）

| 行 | 内容 | 排版 |
|---|---|---|
| 头部 | 20px 旋转标记 + `DSH-Orbit` | 14 semibold |
| 端口 | `127.0.0.1:3080` | 18 semibold；悬停 `AccentText` + 下划线，点击开 Web |
| 元信息 | `profile web · 插件 12 · 停 2 · 会话 3 · dsh 0.25.4` | 12 tertiary，单行省略 |
| 分隔线 | 1px `Divider` | 左右到内边距 |
| 2×2 | `运行时长 02:06:22` \| `余额 ¥24.45`<br>`今日已用 ¥0.6400` \| `峰谷 距闲时 3:12` | 标签 12 tertiary，数值 14 semibold 等宽数字 |
| 按钮 | `停止`（Standard）+ `打开`（Accent） | 32 高、间距 8、右对齐、底边距 16；**穿透态隐藏** |

- 2×2 是**同一基线的两列**（不是标签一行、数值一行）：标签画在列首、数值右对齐到列右缘；
  列宽 `(320-32-24)/2 = 132`、列距 24、行距 32（行高 20 + 空档 12）、四格数值同基线。
- `会话` 是有 turn 在飞的会话数（近似）；取不到显示 `—`，不回退成 0。
- `峰谷`：标准价 `距闲时 h:mm`（`Caution`），闲时 `闲时余 h:mm`（`Success`），未知 `—`。
  口径按 DeepSeek 官方 2026 规则（2026-08-17 起）：高峰 = 北京时间**周一至周五（不含中国法定节假日）
  9:00–12:00、14:00–18:00**（左闭右开），其余全部是闲时——周末、法定节假日全天、工作日 12:00–14:00
  与 18:00–次日 9:00。所以「距闲时」最长 3 小时，「闲时余」会跨周末甚至整段长假，小时数可以是两位数
  甚至三位数（`闲时余 400:00` 是上界）。两侧宽度因此不再对称，数值右对齐到列右缘，超宽走省略号。
  节假日年表：`timor.tech` → jsDelivr / `holiday-cn` → 本地缓存（`holidays.json`）→ 仅按星期的近似；
  每天最多刷新一次，失败不影响 UI。
- **穿透态**（`ClickThrough == true`）：**不画两枚按钮**——穿透时点不到按钮，留着是假 affordance；
  按钮槽位保持原高度，改画一行 12 tertiary「鼠标穿透 · 点击落到桌面」，2×2 与卡片高度都不动。
  命中表里也不注册按钮，端口行的命中保留（它没有可见的悬停反馈，不构成误导）。
- **不提供 tooltip**：悬停不弹任何提示，信息一律在浮层里（版本/端口/插件/会话）或托盘里。
- `Hint` 非空时（未安装 dsh / 端口被占 / 启动失败）顶替元信息行，用 12 `Caution` 整行显示。
- 不存在「运行中」药丸：状态已由头部标记承担，浮层里不再重复一次。

**交互时序**（一条时间轴，单 16ms 驱动器；`t` 相对当前相位）

| 相位 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 图标滑出 | 190ms | `EaseOut` | 光标进**拉手热区**（14 宽 × 60 高，以拉手为中心）即触发 |
| 图标让位 | 120ms | `EaseOut` | 44→28、`opacity`→0、沿贴边内移 8 |
| 槽位长大 | 250ms | `EaseEmphasized` | 44×44 → 320×228，锚点 = 贴屏侧边缘 + 垂直中心，圆角恒 16 |
| 内容错峰 | 140/180/220/260ms 起，490ms 全亮 | `EaseOut` | 头部标记随长大同时显影（它是接力来的同一个东西） |
| 收起 | 167ms | `EaseOut` | 浮层缩回 44 槽位 + 淡出 |
| 图标再现 | 140ms（160ms 起） | `EaseOut` | 面板归零后才出现 |

- 触发：光标停在图标上 **500ms**，或**单击**立即展开；光标离开卡片外扩 8px 超过 **400ms** 收起。
- 小图标与大浮层**从不同屏**：展开后图标 `opacity 0`、收起后浮层 `opacity 0`——这是"先收小的、再长大"的硬约束。
- 注意 `EaseEmphasized` 前段很陡（40ms 已到 ~52%），所以整段长大观感约 140ms；这是刻意的，别改成线性。

**三种形态**（决定"收不收"的唯一开关是贴边与否）

| 形态 | 触发 | 形态 | 会不会收起 |
|---|---|---|---|
| **贴边** | `DockSide != None` | 拉手 → 图标 → 浮层 接力 | 会：离开 400ms 逐级收回 |
| **自由** | `DockSide == None` | **完整卡片常驻**（320×228，四角 16） | **不会**：光标离开不做任何事 |
| **穿透** | `ClickThrough == true`（强制自由） | 完整卡片 + 光标处探照灯挖洞 | 不会，且收不到鼠标 |

拖到左右边缘 28px 内吸附 → 变贴边；从贴边拖出来 → 立刻落到完整卡片，并从落点继续可拖（不再为了图标位置挪窗口）。

**贴边隐藏 ⇄ 点击穿透互斥**：两者永远不可能同时为真，开一个就把另一个关掉并落盘。

- **点击穿透 ON** = 桌面挂件形态：**完整卡片常驻**，不贴边、不收成图标、不显示拉手，
  只有光标处的探照灯在挖洞。切换时若原先贴边会先解除，并把窗口夹回工作区（否则从收起态解锁时整张卡还在屏外）。
- **贴边隐藏 ON** = 图标/浮层接力；启用时自动关闭穿透并贴到最近的左右边。
- 穿透期间不推进相位、`DockTo` 直接忽略，所以它不会自己收回去。

**命中区**：拉手（收起态，14×60 热区，进区滑出图标）、图标矩形（左键展开）、端口行（打开 Web）、两枚按钮；
其余区域可拖动。**右键上锁**：贴边时只有图标命中，自由形态下整张卡片任意位置都算
（贴边浮层里不响应右键，避免在按钮区误触）。贴边态下 `RevealFromDock(holdMs)` 供托盘唤出并压制自动收起。

**DPI**：窗口尺寸 = 设计尺寸 × `DeviceDpi/96`（100% → 372×280，125% → 465×350，150% → 558×420）。
切换缩放时**必须按新 scale 重算贴边偏移**（`_dockOffset` 是像素值，不能跨 scale 复用），
否则贴边位置会漂、极端情况下整块卡片被推出屏幕；自由形态只需把窗口夹回工作区。

**无障碍**：`prefers-reduced-motion` 的等价物是"—关闭动画"时标记静止、morph 直接切终态（保留图标/浮层两态），
不靠动画传达状态；状态色与文字始终是唯一信息来源。

**全屏自动隐藏**：前台出现全屏窗口（含无边框全屏）时直接 `Hide()`，退出全屏再 `Show()` 并重放 Z 序，
没有动画（与用户点「隐藏挂件」同款）。它只改窗口可见性，**不写 `config.Visible`**——
「用户想不想看到挂件」是持久意愿，自动隐藏不落盘；全屏期间用户唤出过就整段压制，直到退出全屏。

⌃ / ⌄ = 地址栏的收起、展开按钮（固定住在红绿灯左侧，收起后仍可见）
⟳ = 刷新   ⧉ = 在浏览器打开（两者都在地址框内部右侧）
```

- 标签：高 32、上圆角 8、激活 = `Layer` 底 + 底部 2px `AccentFill` 指示条
- 标签溢出：宽度先按数量均分收缩（`196 → 84`），到最小值仍放不下时改为横向滚动——
  **左右边界各画一道阴影（渐隐 + 边缘压暗）**，不占标签空间；滚动方式：按住标签条拖动（触屏滑动走同一条路径，松手有惯性与回弹）、
  鼠标滚轮、以及 `+` 新建时自动滚到可见处
- 关闭按钮 14px 图标，仅悬停/激活时显示
- `+` 为 32×32 图标按钮，跟在最后一个标签后面（放不下时钉在标签区最右）
- 红绿灯：**macOS 原色**（`TrafficMinimize #FEBC2E` / `TrafficMaximize #28C840` / `TrafficClose #FF5F57`，是设计系统里的显式例外，不跟主题变），
  纯圆点 Ø15、无背板；悬停时圆点提亮并浮出 × / − / + 符号；命中区仍 32×32
- 地址行：**扁平行，没有外框、没有圆角、没有底板**——左侧 16×16 站点图标 + 地址文字（12px 内边距）+ 两个 26×26 图标按钮，直接坐在工具条上；
  悬停时整行提亮一档（`Mix(Mica, HoverLayer, 0.5)`），聚焦时换上 `ControlFill` 并在整行底部画 2px 强调线；
  整行都是可点击的编辑区，工具条与内容之间靠 1px `Divider` 分隔
- 地址行内容（非编辑态自绘，编辑态换成原生输入框）：
  - **站点图标**：WebView2 `GetFaviconAsync`，32×32 缓存后画成 16×16；没有图标时用 `app-window`
  - **scheme 弱化**：`https://` 用 `TextTertiary`，其余用 `TextSecondary`，一眼能看出协议但不抢注意力
  - **加载状态**：刷新按钮位置画旋转弧（33ms 一帧），此时点它是「停止加载」；加载完恢复成 `refresh`
- 收起按钮：`chevron-up` / `chevron-down`，点击走 **12 帧（≈190ms）缓出高度动画**，网页区域跟着上下滑；
  动画期间布局器让开（避免每帧被打回终态），结束后一次性重排 WebView2；状态存 `shell.json` 的 `AddressCollapsed`；
  `Ctrl+L` 在收起态会瞬间展开再聚焦
- 窗口：`DWMWA_USE_IMMERSIVE_DARK_MODE` 跟随主题，圆角走 DWM

│ 外观      │ 外观                                          │ Subtitle 20

```

- 5 个分区：外观（主题、不透明度）/ 挂件（位置三态、贴边、穿透、全屏隐藏、显示挂件）/
  启动（开机启动三态、启动参数、工作目录）/ DSH（Profile、端口、dsh.exe、内置外壳、外壳关闭、显示余额）/
  数据（API Key、状态/余额/插件间隔、复制地址、打开日志、清理日志）
- 日志：启动 + 每日一次自动保留（dsh 日志留最近 20 份 / 14 天，总量 20 MB 兜底；
  `widget.log` 超 2 MB 轮转为 `widget.1.log`）；「清理日志」= 立即轮转当前日志 + 删除旧 dsh 日志，
  只动 `%LOCALAPPDATA%\DSH-Orbit`，不碰 `~/.dsh`，正在写的文件删不掉就跳过
- 导航：行高 40、间距 4、4 圆角；选中 = `OverState(Mica, Hover)` 浅底 + **左侧 3×16 强调条**（不做整块描边）
- 内容：每个分区一张 `Layer` 卡片（8 圆角、上亮下暗描边、海拔 0），行间 16px inset 的 1px 分隔线
- 行高：开关 / 分段 / 滑杆 64，文本字段 76；行内边距 16
- 控件：开关 40×20（整行可点，Tab + Space；滑块恒为 `SwitchKnob` 近白）、
  分段 32 高（3 格 268×32，标签在行首）、滑杆 40 高（步进 0.05，左右键可调）、
  文本字段 = 12 tertiary 标签 + 32 输入框（路径类带「浏览…」）
- 页脚：左「恢复默认 / 保存预设 / 恢复预设」，右「确定 / 取消 / 应用」（左→右，Windows 属性表口径）：
  **确定** = 校验 + 应用 + 关窗；**应用** = 校验 + 应用但保持打开；**取消** = 丢弃并关窗；
  预设存 `preset.json`（单槽位、覆盖式，只存编辑态），没有预设时「恢复预设」置灰；
  校验失败在页脚分隔线下方的细条里用 `Critical` 12px 提示，普通提示（如「预设已保存」）用 `TextSecondary`
- 键盘：`Esc` 取消、`Ctrl+S` 确定、Tab 在控件间移动
- 数据流：面板只改 `SettingsModel`；点「确定 / 应用」后由 `WidgetApp.ApplySettings` 统一应用
  （主题 / 不透明度 / 层级 / 贴边 / 可见性 / 外壳关闭 / 三个刷新间隔 / 开机自启），
  路径 / 端口 / Profile 提示「下次启动生效」
- 入口：托盘「设置…」，或 `DSH-Orbit.exe --settings`（单实例时通过命名管道唤起）
- 渲染验收：`RenderPreview --only settings` 输出 5 个分区 × 浅/深共 10 张
